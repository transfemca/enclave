## 🧪 THE S.P.E.C.I.A.L. ARCHITECTURE
Every line of code is mapped to the **Seven Pillars of Enclave Performance**:

### 💪 [S]TRENGTH: UNYIELDING POWER
- **GPU WATTAGE OVERRIDE:** Most Linux distributions treat your GPU like a civilian. We don't. This script forces **NVIDIA Persistence Mode** and pushes **Power Limits (PL)** to the absolute hardware maximum.
- **WATTAGE CALCULATION:** Dynamically queries your specific card to unlock every hidden watt for stable, high-clock gaming.

### 👁️ [P]ERCEPTION: VISUAL CLARITY
- **SHADER NEURAL-PURGE:** Corrupted shader caches are the #1 cause of micro-stutter. Protocol 24.0 identifies your specific **Steam AppID (38400)** and nukes the bloated cache files across multiple mount points.
- **STUTTER ELIMINATION:** Force-cleans the "Compiling Shaders" bottleneck before you even hit the Main Menu.

### 🏃 [E]NDURANCE: THERMAL STABILITY
- **PRE-FLIGHT DIAGNOSTICS:** Integrates `sensors` and `nvidia-smi` to provide a real-time thermal readout before deployment.
- **SAFE MODE LOGIC:** Includes a **Dry-Run** simulation mode to test kernel compatibility without committing to hardware changes.

### 🎙️ [C]HARISMA: BASH IMMERSION
- **SUPER DUPER MART CONSOLE:** A fully realized **M.U.D.** (Multi-User Dungeon) style boot sequence.
- **TYPEWRITER INTERFACE:** Lore-accurate, skip-capable typewriter text that delivers Paradoxical Enclave Wisdom.
- **TERMINAL ALIGNMENT:** Hard-coded `stty` and `tput` reset strings to ensure your Konsole looks like a high-end terminal, not a broken text file.

### 🧠 [I]NTELLIGENCE: KERNEL DOMINANCE
- **THP (TRANSPARENT HUGEPAGES):** Set to `madvise` to prevent memory fragmentation during high-load firefights at the SBQ.
- **VM_MAX_MAP_COUNT:** Increased to **2,147,483,647**—allowing the game engine to address memory without the typical "Out of Memory" crashes associated with heavy modding or long sessions.
- **SPLIT-LOCK MITIGATION:** Disabled. We remove the kernel's split-lock "protection" to shave off those crucial milliseconds of CPU latency.

### ⚡ [A]GILITY: THE WATCHER AI
- **DETACHED PRIORITIZATION:** While you play, a **Ghost Process** (Detached Watcher) sits in the background. It doesn't sleep. It doesn't eat.
- **AUTO-NICE:** The moment it detects `Fallout76.exe`, it applies a **-20 Priority** and **Real-Time I/O** (ionice) scheduling. Your CPU will prioritize Appalachia over every other civilian process.

### 🍀 [L]UCK: TOTAL RECOVERY
- **LOGGED REVERT STATE:** We don't just change things; we remember them. Every original system value is saved to `/var/tmp/`.
- **EVACUATION PROTOCOL:** Running `./script.sh revert` restores your system to factory-standard civilian settings instantly. No traces left behind.
